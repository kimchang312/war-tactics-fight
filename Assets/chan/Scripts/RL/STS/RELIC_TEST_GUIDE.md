# 47, 48번 전쟁유산 테스트 가이드

## 구현 완료 사항

### 47번 보물지도
- **효과**: 획득 시 다음에 진입한 이벤트 지역이 보물 지역으로 변경됩니다.
- **구현 위치**: 
  - `WarRelicDatabase.cs`의 `TreasureMap()` 함수
  - `GameManager.cs`의 `SetCurrentStage()` 함수

### 48번 무지개 열쇠
- **효과**: 한 챕터에 두 번, 길이 이어지지 않은 지역으로 이동할 수 있습니다.
- **구현 위치**:
  - `WarRelicDatabase.cs`의 `RainbowKey()` 함수
  - `GameManager.cs`의 `OnStageClicked()` 함수
  - `RogueLikeData.cs`의 챕터별 사용 횟수 관리

## 테스트 방법

### 방법 1: RelicTestHelper 스크립트 사용 (권장)

1. **씬에 테스트 UI 추가**:
   - Unity 에디터에서 `RLmap` 씬을 엽니다.
   - 빈 GameObject를 생성하고 이름을 "RelicTestHelper"로 설정합니다.
   - `RelicTestHelper.cs` 스크립트를 추가합니다.
   - Canvas에 UI 패널을 생성하고 다음 버튼들을 추가합니다:
     - "보물지도 추가" 버튼 → `addTreasureMapBtn`에 할당
     - "무지개 열쇠 추가" 버튼 → `addRainbowKeyBtn`에 할당
     - "무지개 열쇠 리셋" 버튼 → `resetRainbowKeyBtn`에 할당
     - 상태 표시용 Text → `statusText`에 할당

2. **테스트 실행**:
   - 게임을 실행하고 맵 씬으로 이동합니다.
   - "보물지도 추가" 버튼을 클릭하여 47번 유산을 획득합니다.
   - "무지개 열쇠 추가" 버튼을 클릭하여 48번 유산을 획득합니다.
   - 상태 텍스트에서 현재 상태를 확인합니다.

### 방법 2: 코드로 직접 테스트

#### 47번 보물지도 테스트

```csharp
// 콘솔에서 실행하거나 테스트 스크립트에서 호출
RogueLikeData.Instance.AcquireRelic(47);

// 다음 이벤트 지역으로 이동하면 보물로 변경됩니다.
// 확인 방법:
// 1. 맵에서 이벤트 지역을 찾습니다.
// 2. 보물지도를 획득한 후 해당 이벤트 지역으로 이동합니다.
// 3. 스테이지 타입이 보물로 변경되고 보물 보상이 나타나는지 확인합니다.
```

#### 48번 무지개 열쇠 테스트

```csharp
// 콘솔에서 실행하거나 테스트 스크립트에서 호출
RogueLikeData.Instance.AcquireRelic(48);

// 연결되지 않은 지역으로 이동 테스트:
// 1. 현재 위치에서 연결되지 않은 다른 지역을 클릭합니다.
// 2. 첫 번째와 두 번째 이동은 성공해야 합니다.
// 3. 세 번째 이동 시도 시 실패 메시지가 나타나야 합니다.
// 4. 챕터를 변경하면 사용 횟수가 리셋됩니다.
```

### 방법 3: Unity 에디터에서 직접 테스트

1. **게임 실행 후 콘솔 명령어**:
   ```
   // 보물지도 추가
   RogueLikeData.Instance.AcquireRelic(47);
   
   // 무지개 열쇠 추가
   RogueLikeData.Instance.AcquireRelic(48);
   ```

2. **상태 확인**:
   ```csharp
   // 보물지도 플래그 확인
   Debug.Log($"다음 이벤트→보물: {RogueLikeData.Instance.GetNextEventToTreasure()}");
   
   // 무지개 열쇠 사용 횟수 확인
   int chapter = RogueLikeData.Instance.GetChapter();
   Debug.Log($"무지개 열쇠 사용 횟수: {RogueLikeData.Instance.GetRainbowKeyUses(chapter)}/2");
   ```

## 테스트 체크리스트

### 47번 보물지도
- [ ] 보물지도 획득 시 플래그가 `true`로 설정되는지 확인
- [ ] 이벤트 지역 진입 시 보물 지역으로 변경되는지 확인
- [ ] 스프라이트가 보물 스프라이트로 변경되는지 확인
- [ ] 보물 보상이 정상적으로 나타나는지 확인
- [ ] 플래그가 자동으로 리셋되는지 확인
- [ ] 한 번만 작동하는지 확인 (두 번째 이벤트는 변경되지 않음)

### 48번 무지개 열쇠
- [ ] 무지개 열쇠 획득 시 정상적으로 추가되는지 확인
- [ ] 연결되지 않은 지역으로 첫 번째 이동이 성공하는지 확인
- [ ] 연결되지 않은 지역으로 두 번째 이동이 성공하는지 확인
- [ ] 세 번째 이동 시도 시 실패하는지 확인
- [ ] 챕터 변경 시 사용 횟수가 리셋되는지 확인
- [ ] 연결된 지역으로는 정상적으로 이동 가능한지 확인
- [ ] 콘솔 로그에 사용 횟수가 정확히 표시되는지 확인

## 예상 동작

### 47번 보물지도
1. 보물지도 획득 → 콘솔: `[보물지도] 다음 이벤트 지역이 보물 지역으로 변경됩니다.`
2. 이벤트 지역 진입 → 콘솔: `[보물지도] 이벤트 지역 (레벨 X)이 보물 지역으로 변경되었습니다.`
3. 보물 보상 UI 표시

### 48번 무지개 열쇠
1. 무지개 열쇠 획득 → 콘솔: `[무지개 열쇠] 획득 완료...`
2. 연결되지 않은 지역 클릭 → 콘솔: `[무지개 열쇠] 연결되지 않은 지역으로 이동합니다. (사용 횟수: 1/2)`
3. 두 번째 사용 → 콘솔: `(사용 횟수: 2/2)`
4. 세 번째 시도 → 콘솔: `[무지개 열쇠] 챕터 X에서 사용 횟수를 모두 소진했습니다. (2/2)`

## 문제 해결

### 보물지도가 작동하지 않는 경우
- `RogueLikeData.Instance.GetNextEventToTreasure()`가 `true`인지 확인
- 이벤트 지역으로 이동했는지 확인 (Event 타입이어야 함)
- 콘솔 로그 확인

### 무지개 열쇠가 작동하지 않는 경우
- `RelicManager.CheckRelicById(48)`이 `true`인지 확인
- 현재 챕터의 사용 횟수 확인: `RogueLikeData.Instance.GetRainbowKeyUses(chapter)`
- 연결되지 않은 지역을 클릭했는지 확인
- 콘솔 로그 확인
